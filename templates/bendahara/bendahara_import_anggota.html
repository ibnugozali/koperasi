Import Data Anggota

Upload file Excel (.xlsx) untuk menambahkan data anggota secara batch

Petunjuk Penggunaan:
  1. Download template dengan klik tombol "Download Template"
  2. Buka file CSV dengan Microsoft Excel atau LibreOffice Calc
  3. Isi data anggota sesuai dengan format yang ada di template
  4. PENTING: Setelah mengisi data, pilih "Save As" → Pilih format "Excel Workbook (.xlsx)"
  5. Upload file .xlsx yang sudah diisi (bukan file .csv)
  6. Password default untuk setiap anggota adalah NIK mereka (dapat diubah setelah login pertama)
  7. Status anggota akan otomatis diset sebagai "aktif"
Perhatian!
  • Pastikan Unit Kerja sudah sesuai (contoh: Dosen, Staff, Mahasiswa)
  • Format tanggal lahir harus YYYY-MM-DD (contoh: 1990-05-15)
  • NIK harus 16 digit angka
  • Jenis kelamin harus diisi dengan "Laki-laki" atau "Perempuan"
  • Semua data yang duplikat atau tidak valid akan di-skip saat import
